## Project Overview
This project explores international oil trade data. It identifies the top exporting and importing nations and uses machine learning to understand the relationship between proven reserves, production, and consumption.

## Key Features
* *Trade Balance Visualization:* Comparing Imports vs. Exports for major nations like India and the USA.
* *Top 10 Analysis:* Pie charts visualizing the market share of the world's leading oil exporters (e.g., Saudi Arabia, Russia, Canada).
* *Predictive Modeling:* Implementation of a *Linear Regression* model to forecast oil transport needs based on production and consumption metrics.

## Technical Stack
* *Language:* Python
* *Libraries:* Pandas, Matplotlib,numpy
* *Models:* Linear Regression
* *Evaluation Metrics:* Mean Squared Error (MSE), R² Score

## Key Insights
* *Top Exporter:* Saudi Arabia leads with the highest export volume.
* *Top Importer:* The United States shows the highest import dependency in this dataset.
* *Model Accuracy:* The Linear Regression model achieved an R² score of *0.82*, indicating a strong correlation between the chosen features and oil transport quantities.
